# 💘 **LovePulse** – A Romantic Love Calculator

Welcome to **LovePulse**, a charming and visually captivating **love calculator** that helps users discover their "love compatibility" with a touch of animation and music. Whether it’s a fun gesture or a light-hearted way to express affection, LovePulse combines beautiful UI and delightful interactions!

![LovePulse UI](https://your-screenshot-link.com)  <!-- Optional screenshot -->

---

## 🌟 **Features**

- 🎨 **Glassmorphism UI**: A beautiful and smooth glassy design with **romantic gradient** backgrounds.
- ❤️ **Falling Hearts**: Watch heart emojis fall from the top, creating a whimsical and romantic atmosphere.
- 🎶 **Background Music**: Soft, calming **romantic instrumental music** that plays when the user interacts with the page.
- ✍️ **Typing Animation**: Results are shown with a dynamic **typing animation** for a more engaging experience.
- 📷 **Export Results**: Users can save their love compatibility result as an image with the click of a button.
- 🔍 **Responsive Design**: Fully optimized for mobile devices, ensuring a smooth experience across all screen sizes.

---

## 🧮 **How It Works**

Simply enter **two names** – your name and your loved one’s name. LovePulse calculates your **compatibility percentage** based on a fun formula that adds the length of both names and applies some love magic. The result is displayed with heart animations, a **typing effect**, and calming background music!

## 🚀 **Getting Started**

### Clone the repo and run it locally:

```bash
git clone https://github.com/yourusername/lovepulse.git
cd lovepulse
```
open index.html
Alternatively, you can simply open the index.html file in your browser.

Note: Autoplay restrictions in modern browsers mean the music will only play after the first user interaction (click or keypress).
